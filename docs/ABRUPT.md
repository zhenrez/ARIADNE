# ABRUPT — ARIADNE Browser Research Utility Protocol for Trustworthiness

**Status:** ACTIVE / CANONICAL BROWSER EXECUTION PROFILE  
**Adopted:** 2026-09-18  
**Parent instrument:** ARIADNE  
**Relationship:** `ABRUPT ⊂ ARIADNE`

ABRUPT is the browser/chat execution surface of ARIADNE. It is not a separate project, research program, evidence store, or parallel methodology.

All canonical ARIADNE requirements remain active while ABRUPT is in use.

## Browser-specific trustworthiness additions

### Layer-0 corpus discipline
Before synthesis on a newly opened textual anomaly:
- map exact carrier/form;
- map occurrence/distribution and lexical neighborhood;
- follow roots/derivatives with a stopping rule;
- map rhetorical register;
- run a nearest control;
- mark corpus fact / scholarship / tradition / inference / machine proposal separately;
- sweep relevant textual/reception layers;
- record gaps as findings.

### Typed claim/provenance graph
Use, where applicable:
`ASSERTED_BY`, `ATTRIBUTED_TO`, `PRESERVED_BY`, `QUOTES`, `CITES`, `COPIED_FROM`, `DEPENDS_ON`, `INDEPENDENT_OF`, `AGREES_WITH`, `CONTRADICTS`, `PREDATES`, `POSTDATES`, `TRANSLATES`, `REVISES`, `GLOSSES`, `RECLASSIFIES`, `REOPENS`, `TESTS`, `GUIDES_TO`.

A stance-bearing edge carries provenance, date/layer, exact evidence location, relation confidence, claim scope, and dependency notes.

### Full discrepancy branch preservation
For every material alternative, carry each branch through:

```text
SOURCE FORM
→ PRONUNCIATION / VOCALIZATION
→ MORPHOLOGY
→ LITERAL TRANSLATION
→ CONTEXTUAL TRANSLATION
→ ABSTRACTION CLASS
→ SYSTEM CONSEQUENCE
→ WITNESS / TRANSMISSION HISTORY
```

Use:
- E = event
- U = utterance/carrier
- D = decoder/reading rule
- A = abstraction class

Do not change E merely because D changes.

### Name-analysis rule
The analysis object is the **presented carrier in the relevant occurrence**.
For the active 36×2 test:
- `W_i` = whole presented-name semantic object
- `R_i` = one strongest historically licensed complete root/morphological analysis
- secondary alternate segmentations remain attached but do not increment the primary count.

### Period-locked decoder rule
Only operations attested in or before the target period may explain the target-period decoder. Later systems may be used only as explicitly labeled reception controls.

Current lanes:
- Semitic alphabetic numeration
- alphabetic-number decoding
- Greek isopsephy
- keshafim
- `oḥez et ha-ʿenayim` as the eye-deception counter-class

Exact carrier → exact historical script → exact orthography → period-valid mapping → deterministic calculation → corpus comparison → historical/contextual filter.

Equal values generate candidates, not historical conclusions.

### Robustness gate
Before promoting a structural claim, attempt to break it using legitimate alternate segmentation, spelling/witness, chronology, corpus boundary, dependency-collapse, removal tests, controls, translation drift, and holdout prediction where possible.

### Restricted “bright red”
“Bright red” is not a synonym for important. It is reserved for the previously frozen compound morphology only. Ordinary high-value findings use explicit labels such as `HIGH_PRIORITY`, `HIGH_DIAGNOSTIC_VALUE`, or Torch states.

Run at:
- every checkpoint;
- before major synthesis promotion;
- after a major correction/new lock;
- after chronology/provenance contradictions;
- at major domain/century/script/decoder transitions.

Audit at minimum:
- P0 compliance;
- source proximity;
- period contamination;
- dependency vs independence;
- guidance vs evidence;
- branch completeness;
- morphology discipline;
- spelling/numbering normalization;
- residual retention;
- controls;
- robustness testing;
- return breadcrumbs;
- Torch callbacks;
- TOL/checksum containment;
- restricted bright-red usage;
- checkpoint/push freshness;
- verified vs unverified Warden runtime/feed status.

If drift occurs:

```text
DETECT
→ RECORD
→ IDENTIFY FIRST AFFECTED STEP
→ MARK DERIVATIVES AT RISK
→ REWIND TO LAST VALID GATE
→ RERUN
→ SUPERSEDE, NEVER SILENTLY OVERWRITE
```

## Runtime rule

ABRUPT research is ARIADNE research whether or not the local Warden is running.

However, **continuous background processing is only claimed when Warden runtime/feed status is directly verified**.

Without a verified bridge, the browser assistant must keep ARIADNE current by durable checkpoints/pushes and mark local-runtime work `UNVERIFIED_RUNTIME`.

## Transfer rule

A replacement chat loads:
1. current ABRUPT version;
2. latest ARIADNE checkpoint;
3. active-focus packet;
4. relevant sources/tables/workbooks;
5. Torch subset;
6. quarantine/disqualification record;
7. repository refs.

It resumes from the last valid gate rather than rebuilding the project from memory.
